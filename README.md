# Kavin's Portfolio

A personal portfolio website showcasing my education, skills, projects, certifications, and achievements.

## Tech Stack

- **React** + **TypeScript** — UI framework
- **Vite** — Build tool & dev server
- **Tailwind CSS** — Utility-first styling
- **shadcn/ui** — Component library

## Getting Started

```sh
# Install dependencies
npm install

# Start dev server
npm run dev
```
